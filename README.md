# Simple DAO (Soroban Smart Contract)

## Project Description
Simple DAO is a lightweight decentralized governance smart contract built on the Stellar Soroban platform. It allows users to create proposals and vote on them in a transparent and decentralized manner.

## What it does
- Users can create proposals with a description.
- Community members can vote for or against proposals.
- Vote counts are stored on-chain.
- Anyone can fetch proposal details.

## Features
- Decentralized governance model
- Simple and efficient voting mechanism
- On-chain proposal storage
- Transparent vote tracking
- Minimal gas/fee usage (optimized for Soroban)
